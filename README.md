LAST SAVE - a GTA VI trophy guide and missable timeline. An offline web app that tracks all 55 official PS5 trophies for Grand Theft Auto VI: a visual missable timeline with the Chapter 1 point of no return, per-chapter spoiler protection, a checkable meditation spot grid for Positive Mental Attitude, per-trophy guides written in our own words citing their sources, and a source audit view with confidence badges (confirmed / single source / unconfirmed / sources disagree). Progress is stored in the browser, with export and import. Unofficial fan guide; not affiliated with Rockstar Games or Sony.

## Run it

```sh
# any static server works, for example:
python3 -m http.server 8000 --directory app
# then open http://localhost:8000 - or just open app/index.html directly;
# the app runs fully offline, including from file://
```
